# Week 7: The Daily Grind (Punch Cards) - Solution

One valid solution to the Week 7 critical thinking problem. Yours can be different and still be right.

## Files

- `punch_card_tools.py` - the `PunchCard` class (the toolbox)
- `punch_card.py` - the program that makes the cards and runs the menu (the file you run)

## Run it

Put both files in the same folder, open `punch_card.py`, and run it (VS Code: the Run button, or `python punch_card.py` / `python3 punch_card.py` in the terminal).

## Try this

Buy 8 drinks for Ava, show the cards, redeem Ava's free drink, then quit. The end-of-day report should say **8 drinks**: the free drink isn't a sale, and Ava's punches went back to 0, so the card keeps a separate count of drinks bought.
